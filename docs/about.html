The honest part: what's actually free

Free streaming is real. Free unlimited storage is not. Here's the truth so you don't hit a wall later.

The bandwidth is easy. 4 simultaneous 2K streams ≈ 60 Mbps. Oracle's 10 TB/month egress covers ~370 hours of that. Your real limits are storage (200 GB free ≈ a curated library, not "everything") and transcoding (the free ARM box has no GPU — so keep files in direct-play formats).
Recommendation: start on Oracle Always Free with a curated 2K library — it fully meets "4 people, 2K, no buffering, $0." Outgrow 200 GB? Move the exact same compose file to a Hetzner VPS + Storage Box. Nothing else changes.

Deploy it

On a fresh Ubuntu box (Oracle ARM, any VPS, or an old PC).

  1. Spin up the VM. Oracle Cloud → VM.Standard.A1.Flex (2 OCPU / 12 GB), Ubuntu 24.04, 200 GB disk. Open ports 80 + 443 in the Security List.
  2. Point a domain at it. Free via DuckDNS → set two names (watch. / request.) to the VM's public IP.
  3. Clone & run one script.
git clone https://github.com/danielzaiser91/homestream.git
cd homestream
cp .env.example .env      # set domains, email, media path
nano .env
sudo bash scripts/bootstrap.sh
  1. Finish the wizard. Open https://watch.<domain>, create your admin user, add libraries at /media/movies and /media/shows.
  2. Add media & viewers. Copy your files in, add up to 4 Jellyfin users, tell their apps to prefer direct play. Done.

What you put on it

HomeStream is the server — like owning a shelf of Blu-rays and a good TV. It does not download copyrighted content.

✅ Legit to host

Your own DVD/Blu-ray rips, DRM-free purchases, home videos, and huge public-domain / Creative-Commons libraries (Internet Archive, Blender open movies).

🚫 Not included

The "arr" auto-download stack from those Reddit guides pirates current movies/TV. This project deliberately leaves it out and stops at server + UI + hosting.
